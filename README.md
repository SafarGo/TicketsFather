# Kinobot MVP: персональные кино-подборки и выгодные билеты в Telegram

Бот собирает расписание кинотеатров Еревана (КиноМосква, Cinema Star), находит выгодные сеансы и новинки и присылает
посты с постером, описанием, ближайшим сеансом и **прямой ссылкой на покупку билета**. Подборка строится по
вишлисту и вкусу пользователя (импорт из Letterboxd или поиск по названию).

## Быстрый старт

Нужен Python 3.11+.

```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                   # и заполните его
```

В `.env`: `BOT_TOKEN` (от @BotFather), `TMDB_API_KEY` (themoviedb.org → Settings → API), `ADMIN_CHAT_ID`
(ваш Telegram ID, например из @userinfobot).

**Сначала проверьте парсеры без бота:**

```bash
python -m kinobot collect     # один раз собирает сеансы, печатает отчёт и ошибки
python -m kinobot deals       # показывает найденные выгодные сеансы
python -m kinobot run         # запускает бота
```

Через Docker: `docker compose up -d --build`.

## Что умеет бот

| Команда | Что делает |
|---|---|
| `/start`, `/city` | выбор города |
| Файл `.zip` / `watchlist.csv` / `ratings.csv` | импорт из Letterboxd (Settings → Data → Export) |
| Название фильма текстом | поиск, кнопки «🔖 в вишлист» и «❤️ нравится» |
| `/feed` | показать подборку прямо сейчас |
| `/wishlist`, `/settings`, `/pause`, `/resume` | вишлист, лимиты (постов в день, цена), пауза |
| `/stats`, `/unmatched`, `/link`, `/collect` | только для админа: статистика, фильмы без привязки к TMDb, ручная привязка, запуск сбора |

Типы постов: **🔖 ВЫ ХОТЕЛИ ПОСМОТРЕТЬ** (фильм из вишлиста появился в афише), **💸 ВЫГОДНО!**,
**🆕 НОВИНКА!**, **🎁 АКЦИЯ!** (новая акция сети). Под постом: «Купить билет», «В вишлист», «Не интересно».

## Как это устроено

```
адаптеры сайтов → коллектор → привязка к TMDb → SQLite → генератор событий → рендер поста → рассылка
```

- `adapters/` один адаптер на сайт; результат единого формата `FetchResult`. Новый сайт = новый файл.
- `collector.py` собирает, привязывает названия к фильмам, пишет в базу, помечает пропавшие сеансы неактивными
  (только в тех датах, которые удалось загрузить полностью), шлёт админу алерт, если парсер сломался.
- `matcher.py` приводит «Диггер (RUS)», «Digger» и т. п. к одному фильму TMDb. Незнакомое (например, армянское
  кино) сохраняется как локальный фильм; исправить можно через `/unmatched` и `/link`.
- `events.py` правила: **выгодно** = цена не выше 70% от медианы для этого фильма в этом кинотеатре, экономия от
  500 драм, VIP не считается (пороги в `config.py`); **новинка** = выход в прокат в последние 14 дней или
  появление в афише после запуска бота; один пост на фильм, антиповтор, дневной лимит, тихие часы 23:00–09:00.
- `taste.py` простой профиль вкуса по жанрам и режиссёрам из ваших оценок, вишлиста и «не интересно».

## Что проверено, а что нет (важно)

**Проверено** (73 автотеста, `python -m unittest discover -s tests -t .`): разбор настоящих страниц КиноМосквы и
Cinema Star (HTML лежит в `tests/fixtures`), привязка названий, база, события, рендер, лимиты, импорт Letterboxd,
логика обработчиков бота.

**Не проверено**, потому что при разработке не было доступа в интернет:

1. **Живые запросы к сайтам.** Парсеры проверены на сохранённых страницах, но не на живых ответах.
2. **Cinema Star: переключение дат и филиалов.** Клиент Livewire написан по структуре страницы и протоколу
   Livewire 3 (`POST /ru/livewire/update`). Если сайт ответит иначе, `collect` покажет ошибку в строке
   `cinemastar[...]`; тогда пришлите вывод, и я поправлю. Сеансы «сегодня в первом филиале» работают и без этого.
3. **Настоящий aiogram.** Обработчики тестировались на заглушке, не на живом Telegram.
4. **TMDb.** Клиент написан по документации API, но с реальным ключом не запускался.

## Чего пока нет

- **Kinopark**: сеансы грузятся скриптом, нужен адрес запроса (вкладка Network) и пример ответа. Заготовка:
  `adapters/kinopark.py`.
- Акции Cinema Star (страница `/promos` подгружается лениво); акции КиноМосквы собираются.
- Новости кино, друзья, клик-аналитика (кнопка ведёт напрямую на сайт кинотеатра), несколько городов.
- SQLite достаточно для старта; при росте переедет на PostgreSQL.
